# Void Pointer with Array Elements

## Author
M.Likitha

## Description
This program demonstrates how a void pointer can be used
to pass an integer array to a function.

Inside the function, the void pointer is converted into
an integer pointer so that the array elements can be accessed.

## Concepts Used
- Void pointer
- Integer array
- Functions
- Type casting
- Array traversal
- Pointer notation

## How to Run

gcc void_pointer_array.c -o void_pointer_array

./void_pointer_array

## Sample Output

10 20 30 40 50
